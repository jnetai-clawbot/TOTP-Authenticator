# Changes

## v1.1.8

- FEAT: QR code scanning to pair accounts like Google Authenticator
  - "Scan QR Code" button added to the Add Site dialog
  - Use Camera to scan an otpauth:// QR code directly
  - Choose Image to upload a PNG/photo of a QR code from the gallery
  - Parses otpauth://totp/ and otpauth://hotp/ URIs (name, secret, issuer auto-filled)
  - Handles rotated/large photos during image decode
- CHORE: Version bumped to 1.1.8 (versionCode 12)

## v1.1.7

- FIX: Google Drive sync now uses system file picker (SAF) — no Google API keys needed
  - No more Google Cloud Console / SHA-1 fingerprint / OAuth setup
  - Users pick their cloud storage (Drive, Dropbox, local, etc.) from the file picker
  - Backup is encrypted with master password before saving
  - Restore decrypts with master password
- FEAT: Added Check for Updates button in About dialog
  - Queries GitHub API for latest release
  - Shows current version vs latest release
  - "Download Update →" button opens the releases page
- FIX: Added INTERNET and ACCESS_NETWORK_STATE permissions (already present)
- CHORE: Removed unused google-http-client-gson dependency
- CHORE: Version bumped to 1.1.7 (versionCode 11)

## v1.1.6

- Added release signing configuration with keystore.jks (alias: authenticator)
- Added proguard-rules.pro for release build optimisation
- Updated GitHub Actions workflow to build both debug and release APKs
- Release APK now signed for direct install on Samsung S7, S8, Pixel 6, Pixel 7
- Keystore password stored in KEYSTORE_PASSWORD / KEY_PASSWORD env vars
- MinSDK 24 covers all target devices
- APKs renamed to totp-debug.apk / totp-release.apk for clarity
- GitHub Releases now auto-created with meaningful names (TOTP Authenticator vX)
- APKs stored locally in apk/ with matching names
